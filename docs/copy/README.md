# FinaShop copy reference

`fina_shop.{ar,en}.json` are the Arabic and English UI strings from the live
fina.shop app (extracted from its JS bundles, Nov 2026). Reuse this wording
when adding keys to `config/locales/*.yml` so our copy matches FinaShop.

Examples: `homePage.*` (landing), `nav.*` (admin sidebar), `requestStatus.*`,
`quoteStatus.*`, `productForm.*`, `storeSettingsForm.*`, `onboarding.*`.
